使用帮助

这是一个公开的原创示例课程，供 Apple 审核和安装前体验使用，无需任何学校账号、密码或通行密钥。

从安装到下载

  1. 安装后启动 App，点击“打开 Safari 扩展设置”，勾选启用。
  2. 在 Safari 登录自己的 Moodle 网站，打开课程页或章节页。
  3. 点击工具栏的课件下载器图标，按提示授予当前网站访问权限。
  4. 用类型开关筛选，逐项勾选或使用“全选”“清空”。
  5. 点击“准备所选文件”，检查格式和逐项错误，再点击“下载”。
  6. 打开 Safari 下载列表查看结果。单项失败时，可以使用“单独下载”。

打开示例课程

为什么没有找到某些资料？

当前版本只识别已加载的标准 File 文件模块。不扫描提交活动、测验、问卷、URL、Folder、Book 或 Page 中的附件。展开或访问所需章节后重新打开面板；特殊主题可能不兼容。

为什么批量下载没有开始？

检查 Safari 设置 → 网站 → 下载，对当前 Moodle 网站选择“允许”。下载目录跟随 Safari 通用设置。如果设置为每次询问，Safari 仍可能逐个询问。扩展不会自动改变这些设置。

提示登录失效、跨域或文件不存在怎么办？

先在 Safari 重新登录 Moodle 并直接检查该资源的访问权限，再回到课程页重试。外部仓库不支持；文件删除或访问受限需联系课程教师。

准备文件是否会改变课程完成状态？

可能会。准备阶段会访问所选 File 资源，Moodle 可能将其记录为已查看。只打开面板扫描当前页面不会主动请求文件。

能否改名、创建文件夹或查看下载进度？

扩展不提供这些功能。文件名来自服务器，保存位置和传输状态由 Safari 管理。
