Help and support

Safari course downloads

  1. Launch Add-in Downloader, choose a language and continue.
  2. Open Extension settings and enable Add-in Downloader in Safari. Grant access only to the course websites you use. Access to every website is not necessary.
  3. Sign in to your course website in Safari and open a course content page. Click the Add-in Downloader toolbar button.
  4. Scan the course. Platform access logs or viewed states may change as resources are requested.
  5. Filter by section, category or extension; select files and prepare them.
  6. Review errors, then start the downloads. Check Safari’s downloads list for completion. The extension reports initiation, not disk completion.

Public Safari sample course

Change language

Use the Language selector in the Mac app or extension panel. The first-use question previews the selected language immediately. Confirm to begin. Your choice is saved locally and shared between the app and extension. The nine supported languages apply to product UI; school pages, filenames and macOS permission dialogs are not translated by this app.

Optional native checks and local example

Choose “Try the sample course” in the Mac app. Click “1. Create baseline” (0 saved), “2. Publish sample file”, then “3. Check for new files” (1 PDF saved). Use “Show in Finder” to locate it. Repeat the check: 0 new files are saved. Exit resets only the example, not saved files or your real account.

For real courses, connect Moodle using a personal Mobile Web Services token or the app’s separate web sign-in. Select courses. The first check creates a baseline; subsequent manual checks save supported new or updated materials to Downloads. Existing local files are not deleted or overwritten; name collisions use numbered suffixes. Safari may be closed. There is no background schedule.

Troubleshooting

  • Missing files: check reported incomplete branches. Unsupported layouts, locked files, inaccessible pages and external services may not be scanned.
  • No download: check Safari’s website download setting and download location. Try the single-file button. Safari controls its own naming conflicts and prompts.
  • Sign-in expired: Safari and the optional Mac app have separate sessions. Reauthenticate in the one reporting the error. The app does not import Safari cookies.
  • Panel reopens: after activation it can reopen in the same tab on the same permitted course site. Close the panel to stop this.
